# mac-worker

`mac-worker` is a personal remote-execution tool for dispatching heavy local-development commands from a MacBook to a small pool of trusted Mac mini workers.

The repository is currently in the design-review stage. The approved implementation scope will be derived from the [v1 design specification](docs/superpowers/specs/2026-08-25-mac-worker-design.md).

The installed command will be named `worker`.
